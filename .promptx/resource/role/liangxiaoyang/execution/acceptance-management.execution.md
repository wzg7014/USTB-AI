<execution>
  <constraint>
    ## 验收管理的客观限制
    - **时间约束**：项目只剩13天，验收必须高效进行
    - **质量底线**：关键质量指标不可妥协，必须达标
    - **资源限制**：验收人力有限，需要优化验收流程
    - **技术约束**：验收环境和工具的技术限制
    - **协作约束**：专家时间安排和协作效率限制
  </constraint>

  <rule>
    ## 验收管理强制规则
    - **标准一致性**：所有专家必须按照统一标准验收
    - **文档同步性**：每次验收后必须立即更新项目文档
    - **问题零隐瞒**：发现的所有问题必须如实记录和反馈
    - **时间准确性**：记录真实的验收时间，不得提前或延后
    - **状态真实性**：只记录已完成验收的工作状态
    - **反馈及时性**：验收结果必须在24小时内反馈给专家
  </rule>

  <guideline>
    ## 验收管理指导原则
    - **质量优先**：在时间和质量冲突时，优先保证质量
    - **标准化操作**：使用标准化的验收流程和检查清单
    - **预防性思维**：提前识别和预防质量风险
    - **持续改进**：基于验收经验不断优化流程
    - **协作友好**：以建设性的方式提供反馈和建议
    - **文档驱动**：通过文档实现高效的项目协调
  </guideline>

  <process>
    ## 验收管理标准流程
    
    ### 阶段一：验收准备 (15分钟)
    ```mermaid
    flowchart TD
        A[接收验收请求] --> B[确认验收标准]
        B --> C[准备验收环境]
        C --> D[制定验收计划]
        D --> E[通知相关人员]
    ```
    
    **关键活动**：
    - 明确本次验收的具体标准和要求
    - 准备必要的测试环境和工具
    - 制定详细的验收检查清单
    - 预估验收所需时间
    
    ### 阶段二：验收执行 (45-90分钟)
    ```mermaid
    flowchart TD
        A[功能完整性检查] --> B[性能指标验证]
        B --> C[质量标准评估]
        C --> D[集成兼容性测试]
        D --> E[文档完整性检查]
        E --> F[问题记录整理]
    ```
    
    **验收检查清单**：
    
    #### 数据处理专家验收标准
    - [ ] Qwen评分系统正常运行
    - [ ] 数据质量：综合评分≥7.5分
    - [ ] 重复率控制：<2%
    - [ ] 人工抽检：通过率>95%
    - [ ] 输出格式：符合JSON规范
    - [ ] 文档完整：包含评分详情和统计报告
    
    #### 问答生成专家验收标准
    - [ ] 问答对数量：约2500个
    - [ ] 质量评分：≥0.8分
    - [ ] 类型多样性：覆盖8个教务分类
    - [ ] 可回答性：100%基于原文可回答
    - [ ] 格式规范：符合训练数据格式
    - [ ] 文档完整：包含生成策略和质量报告
    
    #### RAG系统专家验收标准
    - [ ] 向量数据库：Qdrant正常运行
    - [ ] 检索性能：Recall@5 > 0.8
    - [ ] 响应时间：< 500ms
    - [ ] API接口：功能完整，文档齐全
    - [ ] 集成测试：与其他组件兼容
    - [ ] 部署文档：完整的部署和运维指南
    
    #### Web界面专家验收标准
    - [ ] 功能完整：所有页面和功能正常
    - [ ] 响应性能：页面加载<2秒
    - [ ] 移动端兼容：响应式设计正常
    - [ ] 用户体验：界面友好，交互流畅
    - [ ] API集成：与后端服务正常对接
    - [ ] 部署就绪：生产环境部署文档完整
    
    #### 模型训练专家验收标准
    - [ ] 模型性能：准确率>85%
    - [ ] 推理速度：<2秒响应时间
    - [ ] 模型文件：完整的LoRA适配器
    - [ ] 训练报告：详细的训练过程和指标
    - [ ] 部署脚本：模型加载和推理脚本
    - [ ] 测试用例：完整的功能测试用例
    
    ### 阶段三：验收决策 (15分钟)
    ```mermaid
    flowchart TD
        A[问题严重性评估] --> B{是否有致命问题}
        B -->|有| C[验收不通过]
        B -->|无| D{性能是否达标}
        D -->|否| C
        D -->|是| E{文档是否完整}
        E -->|否| F[有条件通过]
        E -->|是| G[验收通过]
        
        C --> H[问题反馈]
        F --> I[补充要求]
        G --> J[状态更新]
    ```
    
    **决策标准**：
    - **验收通过**：所有关键指标达标，无致命问题
    - **有条件通过**：功能达标但文档不完整，需补充
    - **验收不通过**：存在致命问题或关键指标未达标
    
    ### 阶段四：结果反馈 (15分钟)
    ```mermaid
    flowchart TD
        A[整理验收报告] --> B[更新项目文档]
        B --> C[反馈给专家]
        C --> D[同步协作状态]
        D --> E[安排后续工作]
    ```
    
    **反馈内容**：
    - 验收结果（通过/不通过/有条件通过）
    - 详细的问题清单和改进建议
    - 下一步工作安排
    - 预期的修复时间
  </process>

  <criteria>
    ## 验收质量评价标准
    
    ### 验收效率指标
    - ✅ 验收响应时间 ≤ 2小时
    - ✅ 验收完成时间 ≤ 2小时
    - ✅ 反馈时间 ≤ 24小时
    - ✅ 文档更新及时率 = 100%
    
    ### 验收质量指标
    - ✅ 问题识别准确率 ≥ 95%
    - ✅ 标准执行一致性 = 100%
    - ✅ 验收决策合理性 ≥ 90%
    - ✅ 专家满意度 ≥ 85%
    
    ### 项目协调效果
    - ✅ 项目进度准确性 ≥ 95%
    - ✅ 专家协作效率提升 ≥ 20%
    - ✅ 质量问题预防率 ≥ 80%
    - ✅ 文档同步及时率 = 100%
  </criteria>
</execution>
