# USTB AI教务助手 - 混合架构重构版技术方案

## 🎯 项目定位

**面向大厂AI算法工程师岗位的核心技能展示项目**

基于DeepSeek-R1-Distill-Llama-8B的垂直领域AI助手，采用RAG+微调混合架构，专门解决北京科技大学教务场景的智能问答需求。

## 📊 数据现状分析 (2025-08-01 重新评估)

### 原始数据规模
- **总数据量**: 4180条教务数据
- **实际有用数据**: 约500条 (经过质量筛选)
- **主要来源**: notices(4124条) + regulations(56条)
- **数据质量**: 标题重复率8.9%，需要严格清洗
- **预期问答对**: 约2500个 (基于500条有用数据)

### 数据质量筛选方案 🆕 **Qwen智能评分系统**

#### 核心方案: 基于Qwen的6维度智能评分 (最终选择)
- **评分模型**: 使用Qwen-Plus作为数据质量评估器
- **评分维度**: 6个核心维度，权重化综合评分
- **自动化程度**: 完全自动化评分，可解释性强
- **成本**: 免费 (阿里云免费额度足够)
- **优势**: 比传统规则更智能，提供详细评分理由

#### Qwen评分维度设计

##### 1. 完整性 (Completeness) - 权重25%
- **评估标准**: 标题、正文、时间、发布部门、附件信息完整性
- **评分范围**: 1-10分
- **关键问题**: "这条教务通知的信息是否完整，包含了学生需要的所有关键信息？"

##### 2. 相关性 (Relevance) - 权重25%
- **评估标准**: 与教务场景的相关程度，学生关心程度
- **评分范围**: 1-10分
- **关键问题**: "这条通知对USTB学生的教务需求相关性如何？"

##### 3. 时效性 (Timeliness) - 权重20%
- **评估标准**: 信息的时间价值，是否是最新政策或长期有效
- **评分范围**: 1-10分
- **关键问题**: "这条通知的时效性如何？是否仍然有参考价值？"

##### 4. 可用性 (Usability) - 权重15%
- **评估标准**: 信息是否可操作，学生能否基于此采取行动
- **评分范围**: 1-10分
- **关键问题**: "学生能否基于这条通知采取具体的行动？"

##### 5. 准确性 (Accuracy) - 权重10%
- **评估标准**: 信息表述准确性，逻辑清晰度
- **评分范围**: 1-10分
- **关键问题**: "这条通知的表述是否准确清晰？"

##### 6. 信息密度 (Information Density) - 权重5%
- **评估标准**: 单位文本包含的有效信息量
- **评分范围**: 1-10分
- **关键问题**: "这条通知的信息密度如何？是否言简意赅？"

#### 三轮筛选流程
- **第一轮粗筛**: 基础规则快速过滤明显无用数据
- **第二轮精筛**: Qwen 6维度评分系统 (核心环节)
- **第三轮验收**: 人工抽检10%确保质量

#### 筛选标准
- **高质量数据**: 综合评分 ≥ 7.5分 (约400-500条)
- **中等质量**: 6.0-7.4分 (备选数据，约200-300条)
- **低质量数据**: < 6.0分 (直接过滤)

### 去重处理方案 (服务于RAG向量数据库)
- **语义去重**: 基于文本相似度的智能去重
- **URL去重**: 基于链接的精确去重
- **标题去重**: 相似标题合并处理
- **内容去重**: 基于Hash和相似度的双重去重
