# USTB AI教务助手 - 混合架构升级版

## 🎯 项目简介

基于DeepSeek-R1-Distill-Llama-8B的垂直领域AI助手，采用RAG+微调混合架构，专门解决北京科技大学教务场景的智能问答需求。

**核心创新**：
- 🧠 **Qwen智能评分系统** - 6维度数据质量评估
- 🔄 **专家并行开发架构** - 提升开发效率
- 🎯 **混合架构设计** - RAG检索 + LoRA微调

## 🚀 快速开始

### 环境要求
- **GPU**: RTX 4090 (24GB显存)
- **内存**: 120GB
- **Python**: 3.11+
- **CUDA**: 12.1+

### 数据准备
```bash
# 原始数据位置
data/raw/全部原始数据/
├── notices/     # 4124条通知数据
├── regulations/ # 56条规章制度
└── 其他6个分类/  # 教务相关数据
```

### 技术栈
- **项目管理**: PromptX MCP工具链 + RACI责任矩阵
- **微调**: Unsloth + LoRA + DeepSeek-R1-Distill-Llama-8B
- **RAG**: Qdrant + BCE-embedding-base_v1 + LangChain
- **数据评估**: Qwen-Plus API (免费额度) + 双重验证
- **前端**: React/Vue + 响应式设计 + 移动端适配
- **后端**: Flask/FastAPI + RESTful API
- **集成**: Docker + 系统监控 + 自动化测试

## 🏗️ 项目架构

### 8专家三层协作架构
```
           项目经理（梁晓阳）
                  |
    ┌─────────────┼─────────────┐
    │             │             │
  数据层        开发层        集成层
┌─────┴─────┐ ┌─────┴─────┐ ┌─────┴─────┐
│           │ │           │ │           │
数据处理    数据科学   RAG系统   Web前端   模型训练   系统集成
专家        专家      专家      专家      专家      专家
│           │ │           │ │           │
└───────────┘ └───────────┘ └───────────┘
     |             |             |
  问答生成       Web后端      (独立专家)
```

### 数据流转架构
```
4180条原始数据 → Qwen智能评分 → 500条高质量数据 → 2500个问答对
                      ↓
            ┌─────────────────────────┐
            │     8专家并行开发       │
            │                        │
            │ 数据层(3) → 开发层(3) → 集成层(2) │
            │      ↓           ↓      │
            │ 质量双重验证  前后端分离  │
            │ 向量数据库    Web界面    │
            └─────────────────────────┘
                      ↓
            DeepSeek LoRA微调 → 完整AI助手系统
```
