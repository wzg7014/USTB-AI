# USTB AI教务助手 - 混合架构升级版

## 🎯 项目简介

基于Qwen2.5-7B-Instruct的垂直领域AI助手，采用RAG+微调混合架构，专门解决北京科技大学教务场景的智能问答需求。

**核心创新**：
- 🧠 **Qwen智能评分系统** - 6维度数据质量评估
- 🔄 **专家并行开发架构** - 提升开发效率
- 🎯 **混合架构设计** - RAG检索 + LoRA微调
- ⚡ **角色定义系统性升级** - 5大管理机制融入角色定义 (2025-08-04)
- 🚀 **混合云架构突破** - RAG系统200倍性能提升 (2025-08-05)
- 🔧 **模型选择优化** - 切换到Qwen2.5-7B-Instruct，下载中 (2025-08-06)

## 🚀 快速开始

### 环境要求

#### AutoDL云端环境 (主要计算)
- **GPU**: RTX 4090 (24GB显存) - AutoDL租用
- **内存**: 1TB
- **Python**: 3.11+ (Unsloth环境)
- **CUDA**: 12.1+
- **SSH工具**: autodl-ssh-remote (项目内置)

#### 本地开发环境
- **内存**: 16GB+ (Web界面开发)
- **Python**: 3.11+
- **网络**: 稳定网络连接 (SSH隧道)

### 数据准备
```bash
# 原始数据位置
data/raw/全部原始数据/
├── notices/     # 4124条通知数据
├── regulations/ # 56条规章制度
└── 其他6个分类/  # 教务相关数据
```

### 技术栈
- **项目管理**: PromptX MCP工具链 + RACI责任矩阵
- **微调**: Unsloth + LoRA + Qwen2.5-7B-Instruct (AutoDL RTX 4090)
- **RAG**: Qdrant + BCE-embedding-base_v1 + GPU加速推理 (AutoDL)
- **数据评估**: Qwen-Plus API (免费额度) + 双重验证
- **前端**: ChatGPT-Next-Web定制 + USTB主题 + 移动端适配
- **后端**: FastAPI + RESTful API + 混合回答机制
- **集成**: SSH工具 + AutoDL混合云 + GPU加速 + 隧道管理
