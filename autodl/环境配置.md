## 🚀 服务启动详细流程

### 1. RAG服务启动 (端口8000)
```bash
# 1. SSH连接AutoDL
ssh -p 21020 root@connect.bjb1.seetacloud.com

# 2. 进入RAG服务目录
cd /root/autodl-tmp/ustb-project/services/rag_system/

# 3. 激活unsloth环境
source /root/miniconda3/bin/activate unsloth

# 4. 检查依赖
python -c "import fastapi, qdrant_client, sentence_transformers; print('依赖检查通过')"

# 5. 启动服务
/root/miniconda3/envs/unsloth/bin/python rag_service_v2.py

# 6. 验证服务
curl http://localhost:8000/health
curl -X POST http://localhost:8000/api/v1/search -H "Content-Type: application/json" -d '{"query":"选课","top_k":5}'
```

### 2. LoRA推理服务启动 (端口8004)
```bash
# 1. 进入模型推理目录
cd /root/autodl-tmp/ustb-project/services/model_inference/

# 2. 激活unsloth环境
source /root/miniconda3/bin/activate unsloth

# 3. 检查GPU状态
nvidia-smi

# 4. 检查模型文件
ls -la /root/autodl-tmp/ustb-project/models/trained/
ls -la /root/autodl-tmp/models/Qwen2.5-7B-Instruct/

# 5. 启动服务
/root/miniconda3/envs/unsloth/bin/python ustb_lora_inference_server.py --port 8004

# 6. 验证服务
curl http://localhost:8004/health
curl -X POST http://localhost:8004/api/v1/inference -H "Content-Type: application/json" -d '{"query":"请问如何选课？","max_tokens":256}'
```

### 3. Web API连接器启动 (端口8003)
```bash
# 1. 进入Web集成目录
cd /root/autodl-tmp/ustb-project/system/web_integration/

# 2. 激活unsloth环境
source /root/miniconda3/bin/activate unsloth

# 3. 启动连接器
/root/miniconda3/envs/unsloth/bin/python web_api_connector.py --port 8003 --hybrid-url http://localhost:8002

# 4. 验证服务
curl http://localhost:8003/health
curl -X POST http://localhost:8003/api/v1/chat -H "Content-Type: application/json" -d '{"message":"请问如何选课？","max_tokens":256}'
```

## 🔍 故障排查指南

### 常见问题及解决方案

#### 1. 服务无法启动
```bash
# 检查端口占用
lsof -i :8000
lsof -i :8003
lsof -i :8004

# 杀死占用进程
kill -9 <PID>

# 检查Python环境
which python
python --version
```

#### 2. GPU内存不足
```bash
# 检查GPU内存使用
nvidia-smi

# 清理GPU缓存
python -c "import torch; torch.cuda.empty_cache()"

# 重启服务释放内存
pkill -f python
```

#### 3. 模型加载失败
```bash
# 检查模型文件
ls -la /root/autodl-tmp/ustb-project/models/trained/
ls -la /root/autodl-tmp/models/Qwen2.5-7B-Instruct/

# 检查磁盘空间
df -h

# 检查文件权限
chmod -R 755 /root/autodl-tmp/ustb-project/models/
```

#### 4. 网络连接问题
```bash
# 检查SSH隧道状态
ps aux | grep ssh

# 重新建立SSH隧道
ssh -p 21020 -L 8000:localhost:8000 root@connect.bjb1.seetacloud.com

# 检查防火墙设置
iptables -L
```

## 🔄 服务重启脚本

### 快速重启所有服务
```bash
#!/bin/bash
# 文件: /root/autodl-tmp/ustb-project/scripts/restart_all_services.sh

echo "停止所有服务..."
pkill -f rag_service_v2.py
pkill -f ustb_lora_inference_server.py
pkill -f web_api_connector.py

echo "等待5秒..."
sleep 5

echo "启动RAG服务..."
cd /root/autodl-tmp/ustb-project/services/rag_system/
nohup /root/miniconda3/envs/unsloth/bin/python rag_service_v2.py > /dev/null 2>&1 &

echo "启动LoRA推理服务..."
cd /root/autodl-tmp/ustb-project/services/model_inference/
nohup /root/miniconda3/envs/unsloth/bin/python ustb_lora_inference_server.py --port 8004 > /dev/null 2>&1 &

echo "启动Web API连接器..."
cd /root/autodl-tmp/ustb-project/system/web_integration/
nohup /root/miniconda3/envs/unsloth/bin/python web_api_connector.py --port 8003 > /dev/null 2>&1 &

echo "所有服务启动完成！"
```
